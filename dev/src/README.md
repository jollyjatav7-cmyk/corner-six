# 角球六要素

边看比赛边按六个要素记录两队：① 到达禁区附近的能力、② 行动选择（下底传中／45 度传中／突破渗透／远射）、③ 禁区内空间、④ 禁区外空间、⑤ 心态、⑥ 传中和射门的质量，每一项换成 1–5 级，并对照公开数据看这样踢会有多少角球。

- 安装：用 Safari 打开这个仓库的 GitHub Pages 网址 →“分享”→“添加到主屏幕”，联网时打开一次即可离线使用。
- 两边控球：左边记主队控球时、右边记客队控球时发生的事。iPad 一下就点到结果（例如“下底传中·被挡”）；手机先点动作，再在弹出的选单里点结果，8 秒没点就当“结果没记”，次数照样算。
- 计时器：点比分中间的时间（或 ▶）开球、中场、对准画面上的时间；中途才开始看也可以。
- 频率：每个动作按键下面写着“现在 x · 平均 y 次/10分”和等级。现在＝这个半场你记的次数 ÷ 看的分钟 × 10，平均＝所有球队的平均；现在是平均的 1.5 倍以上“很快”、1.2 倍以上“快”、差不到两成“平均”、0.83 倍以下“慢”、0.67 倍以下“很慢”，看得还不够久显示“还早”。“数据”分页有每种结果的频率。
- 六项：iPad 在中间卡片，手机在上方摘要条（点开是完整的表）。每一格可以点开看说明或改成手动评级。下面有“动作折算”（按你记下的结果，平均应该有几个角球）和“接下来”（本半场、全场的角球）：用“角球数据记录”的模型算时段、主客场、比分（领先的一方角球少、落后的多）、红牌和刚有角球的影响，再乘上六项（连上联网时加上联网的角球、射门、控球）的倍数，表里会写出各项倍数。
- 传中到人后接着头球或射门：手机上选“到人”会直接弹出射门结果，点一下就记好禁区射门；没有射门就按“没射门”或等它自己收起。下底传中和 45 度传中的分界是禁区前沿那条线往边线延长，平齐的算下底传中。
- 联网（可选，免费）：直接用“角球数据记录”里的 API-Football key，不用再填（没有的话在“功能 → 联网数据”贴上）。输入球队中文名（填一队也行）就自动找到这场比赛；比赛已经在踢时会弹出“中途加入”，时间（扣掉你的画面延迟）、比分、上下半场角球、红牌都填好，按一下就开始。记录时按底部“同步”才会联网（默认不自动同步，省额度；要自动可以在“功能 → 联网数据”打开），联网比你多的角球、进球、红牌会等画面追上后才补上（标“联网”），你自己点到了就不会重复。联网的角球、射门、控球只用在“接下来”的估计，不会混进六项。
- 视频浮窗：一台手机边看画中画边记录时，在“功能 → 视频浮窗”选浮窗在上方或下方，app 会空出位置。
- 比赛仓库：结束时选“加入仓库”，画面会换成“这场已经结束”，按“开始新比赛”就记下一场（已结束的那场不会再被改到；要接着记录就按“重新打开”）。可以搜索、打开、导出、删除；“统计”有各联赛平均进球和角球、你的六项平均对比公开数据、每个等级的平均角球（检验你的逻辑）；“备份”可以导出 JSON（能再导入、能传给 Claude 分析）或表格 CSV。
- 对比基准：默认跟公开数据比；记满 10 场整场后可以改成跟你自己的记录比。
- 数据只存在设备上。跟“角球数据记录”放在同一个网域，但存放位置分开，互不影响（只会读它的 API key 和队名对照，不会改它的资料）。

公开数据：[StatsBomb Open Data](https://github.com/statsbomb/open-data)（2015/16 英超、西甲、意甲、法甲共 1,517 场；另用 2018–2024 世界杯、欧洲杯、美洲杯、非洲杯 314 场做检验）。
